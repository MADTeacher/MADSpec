# Другие Процессы

Этот раздел описывает сквозные команды, которые можно запускать после появления заметного набора изменений и контекста ветки.

Все команды этого раздела должны начинать с чтения и применения навыка `madspec-cli-operator`.

## Команды

- [`madspec.memory`](madspec.memory.md) — разговорная навигация по слоям объяснения и диагностики структурированной памяти
- [`madspec.merge`](madspec.merge.md) — разговорная подготовка слияния памяти между ветками и продвижения знаний на уровень проекта
- [`madspec.policy`](madspec.policy.md) — разговорное управление правилами проекта через цикл предложения и применения
- [`madspec.change`](madspec.change.md) — разговорное управление пакетом изменений ветки через фиксированную базовую точку сравнения и цикл предложения
- [`madspec.gate`](madspec.gate.md) — разговорная работа с контрольными проверками, блокировками переходов и предложениями на исключения
- [`madspec.deploy`](madspec.deploy.md) — фиксация и уточнение плана развертывания для текущей ветки
- [`review`](madspec.review.md) — анализ качества реализации, соответствия замыслу ветки и списка улучшений
- [`security`](madspec.security.md) — аудит безопасности и приватности по коду, зависимостям, архитектуре и обработке данных

## Общие свойства

- эти команды привязаны к текущей ветке и опираются на `.madspec/<BRANCH>/memory/`
- `madspec.merge` дополнительно использует предложения на слияние и их историю внутри `.madspec/system/memory/memory.sqlite`
- `madspec.change` дополнительно использует `.madspec/<BRANCH>/change/` как каноническое состояние набора изменений
- `madspec.gate` дополнительно использует `.madspec/<BRANCH>/gates/` как канонический слой исключений и аудита запусков
- производные артефакты не блокируют выполнение, но используются как дополнительные источники подтверждений
- основным результатом работы являются проверенные записи, вопросы, решения и отложенные действия в структурированной памяти
