# Служебные CLI Команды

В MADSpec также есть небольшой набор служебных команд помимо `init`, `git` и `memory`.

## `madspec check`

Проверяет, есть ли в локальной среде основные инструменты, на которые рассчитывает MADSpec.

### Когда Использовать

- чтобы проверить рабочую среду перед стартом проекта
- чтобы убедиться, что нужные инструменты AI-агента установлены

### Что Проверяет

- `git`
- CLI-инструменты поддерживаемых AI-агентов там, где они нужны
- `code`
- `code-insiders`

### Синтаксис

```bash
madspec check
```

## `madspec migrate`

Мигрирует старую структуру `.madspec/` в раскладку `.madspec/<branch>/`, которую использует текущий CLI.

### Когда Использовать

- если вы открыли старый проект, где артефакты лежат в корне `.madspec/`
- если нужно перенести существующие артефакты в текущую структуру по веткам

### Синтаксис

```bash
madspec migrate
```

### Что Делает

- определяет активную целевую ветку
- переносит артефакты из корня `.madspec` в `.madspec/<branch>/`
- обновляет `.madspec/config.json`
- гарантирует наличие структуры памяти для ветки
- пересобирает производные файлы после миграции

## `madspec version`

Показывает версию CLI, версию шаблона и системную информацию.

### Когда Использовать

- чтобы посмотреть установленную версию CLI
- чтобы сравнить локальную среду с уже зафиксированными проблемами
- чтобы понять, какой релиз шаблона сейчас используется

### Синтаксис

```bash
madspec version
```

### Что Показывает

- версию CLI
- версию шаблона
- дату релиза шаблона
- версию Python
- сведения о платформе и архитектуре
